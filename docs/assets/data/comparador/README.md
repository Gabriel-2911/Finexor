# 📊 FinProfile – GitHub Pages Version

Este projeto demonstra a rentabilidade acumulada de ativos com dados reais (VALE3 como exemplo), exportado em HTML para visualização estática no GitHub Pages.

## Como usar

1. Rode `scripts/generate_html.py` para gerar os dados e gráficos.
2. Publique a pasta `dashboard/` no GitHub Pages.
3. Acesse o `index.html` para ver os gráficos interativos.
